# 🎯 The Office - Quiz App

A fun and interactive quiz application dedicated to **"The Office (US)"** series. Test your knowledge of the world's best workplace with a countdown timer, automatic question changer, and instant answer feedback!

🔗 **Live Demo:** [quiz-app-mu-plum.vercel.app](https://quiz-app-mu-plum.vercel.app)

![The Office Quiz Screenshot](https://res.cloudinary.com/dartdvch1/image/upload/v1752159290/519_1x_shots_so_sqp16g.png)

---

## 🛠️ Tech Stack

- 💻 **JavaScript** – Core functionality and logic
- 🎨 **HTML** – Structure and content
- 💅 **CSS** – Styling and layout

---

## ✨ Features

✅ **Countdown Timer**  
Start the quiz with a 10-minute timer that creates urgency and excitement.

✅ **Question Navigation**  
Navigate through questions using the **Next** button.

✅ **Answer Validation**  
Get instant visual feedback on whether your answer is correct or not.

✅ **Responsive UI**  
Designed using **Bootstrap** to look great on all devices.
